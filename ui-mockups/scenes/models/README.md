# Scene figure models

Stand-ins for silhouette, proportion and colour blocking in the scene mockups. They are not Ender's final characters.

| File | Source | Licence | Used for |
| --- | --- | --- | --- |
| `hooded.glb`, `mage_staff.glb` | KayKit Adventurers Character Pack 1.0 (Rogue_Hooded, staff) by Kay Lousberg | CC0 | The Binder |
| `minion.glb`, `rogue.glb`, `skel_mage.glb`, `warrior.glb`, `staff.glb`, `shield.glb`, `axe.glb` | KayKit Skeletons Character Pack 1.0 by Kay Lousberg | CC0 | Husk, Wisp, Seer and the Bound King, Keeper, and their props |
| `fox.glb` | Khronos glTF Sample Assets, Fox. Model by PixelMannen (CC0), rig and animation by tomkranis (CC BY 4.0) | CC0 and CC BY 4.0 | The Hound |

Each file was trimmed with glTF-Transform to the few animation clips the scenes pose from. `scene.js` recolours the KayKit texture atlases at load time.
