# Economy

No authored assets: prices, contracts, prophecies and the passive tree come from the local reality
service (`Config/DefaultGame.ini` → `ServiceBaseUrl`). The Crossing's stations are
`AEnderRealmInteractable` actors (Bazaar, Crucible, Grimoire, PassiveTree, RealmGate) opening the
matching `WBP_*` menu. Nothing is requested from the service while a Realm is open.
