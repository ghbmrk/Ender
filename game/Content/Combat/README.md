# Combat

Combat is C++ and data (Source/Ender/Combat, AbilitySystem). Content here is limited to
gameplay-effect Blueprints if a designer needs one; the default effects are native.
Hit cues: `GameplayCue.Hit.Normal` (NS_InkImpact_Small), `GameplayCue.Hit.Heavy` (NS_InkImpact_Heavy),
`GameplayCue.Death.Pigment` (NS_PigmentDeath).
