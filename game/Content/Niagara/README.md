# Niagara

Systems the code and cues expect:

NS_InkImpact_Small, NS_InkImpact_Heavy, NS_PigmentDeath, NS_WatercolorTrail, NS_TelegraphCircle,
NS_TelegraphCone, NS_LootBeam, NS_FormReveal, NS_ThreadLash, NS_Sever, NS_Bind, NS_Unravel,
NS_GrandFracture.

Ability systems are spawned by gameplay cues `GameplayCue.Ability.<Name>`; hits by
`GameplayCue.Hit.Normal/Heavy`; deaths by `GameplayCue.Death.Pigment`.
