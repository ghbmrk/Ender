# Audio

Sound cues referenced from enemy definitions (WindupSound, ExecuteSound, DeathSound) and ability
gameplay cues. Suggested names: `SC_<Ability>`, `SC_<Archetype>_Windup`, `SC_<Archetype>_Death`, `SC_LootDrop`,
`SC_FormReveal`. Telegraph sounds must be audible before every enemy attack (0.4 s minimum windup).
