# Items

- `BP_LootDrop` (optional) — Blueprint of `AEnderLootDrop` for the mesh, the loot beam (`OnLootBeam`,
  NS_LootBeam) and the label widget class (`WBP_LootLabel`). Without it the native class is used.
- Forms (valuable loot) render with custom depth stencil 6; other interactables use 5.
- Label colours: common #F2ECDE, rare #597DA2, exceptional #8667A3, high value #C09A50.
