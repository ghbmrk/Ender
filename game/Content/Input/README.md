# Input

`IMC_Binder` and `IA_*` (Enhanced Input), generated from `Content/Data/input.json`. Paths are fixed in
`AEnderPlayerController`. KB/M: WASD, mouse aim, LMB/RMB/1–4 skills, Space evade, Q draught, F interact,
Tab inventory, M map, Alt loot labels, wheel zoom. Gamepad: LS/RS, RT/LT/X/Y/RB/LB skills, B evade,
D-pad up draught, A interact, Menu inventory, View map.
